# WORLD — Кавказская карта знаний

## Структура
- `index.html` — интерфейс
- `style.css` — оформление и адаптивность
- `script.js` — интерактивность
- `world-map.png` — визуальная карта

## Управление
- WASD / стрелки — движение исследователя
- E — взаимодействие с ближайшей открытой локацией
- мышь — перетаскивание карты
- колесо — масштаб
- кнопки + / − — масштаб

## GitHub Pages
Загрузите **содержимое этой папки** в корень репозитория и включите GitHub Pages из ветки `main`, папка `/ (root)`.

Сборка не требует Node.js, npm или серверной части.


## Управление мышью

- ЛКМ по локации — открыть район.
- Зажать ЛКМ на свободной области карты и перетащить — перемещать обзор.
- Колесо мыши — изменить масштаб.
- Кнопки `+`, `−` и центрирования работают мышью.
- Управление персонажем, WASD, стрелки и клавиша E удалены.
