# Исправленная версия интерактивной карты

Исправлено:
- карта масштабируется целиком и сохраняет исходное соотношение 1536×1024;
- изображение карты и SVG-интерактивные контуры всегда совпадают по масштабу;
- нет обрезания карты из-за несовместимых width/height;
- информационная карточка позиционируется относительно карты, а не окна браузера;
- карточка и всплывающая подсказка автоматически зажимаются внутри границ карты;
- при изменении размера окна открытая карточка перестраивается;
- центральные точки/маркеры, похожие на «фигурки», отключены;
- интерактивной областью остаётся весь контур здания/объекта, а не маленькая точка;
- мерцание окон, пульсация, световые маршруты и частицы сохранены.

Для GitHub Pages замените в репозитории:
index.html
style.css
script.js
school-map.png

После загрузки сделайте жёсткое обновление страницы Ctrl+F5 / Ctrl+Shift+R, чтобы браузер не показывал старый CSS/JS.
