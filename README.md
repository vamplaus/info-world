# Математическая школа №1 — живая интерактивная карта

## Что реализовано

1. Полноэкранная загрузочная сцена. Карта на этом этапе скрыта.
2. Последовательность статусов: подготовка → загрузка карты → активация направлений → включение освещения → готово.
3. Экран приветствия с названием школы.
4. Кнопка входа.
5. Кинематографическое появление карты.
6. Атмосферные эффекты: мягкое свечение, световой проход, частицы, пульсирующие точки.
7. Интерактивные здания и направления.
8. Информационные окна по нажатию.
9. Полностью фиксированная карта:
   - нет WASD;
   - нет стрелок;
   - нет перетаскивания;
   - нет масштабирования колесом;
   - нет кнопок + / -.
10. Адаптивная 3:2 сцена, поэтому координаты интерактивных зон не съезжают относительно изображения.

## Запуск

Откройте `index.html` локально или разместите содержимое папки в корне GitHub Pages.

Для GitHub Pages в репозитории должны находиться:

- `index.html`
- `style.css`
- `script.js`
- `school-map.png`
