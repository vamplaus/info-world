# INFO.WORLD 3.0

Полностью переработанная визуальная версия. Ключевой принцип — не «схема с фигурами», а иллюстрированный цифровой город: здания, улицы, мосты, вода, площади, NPC и полноценные изометрические/псевдо-3D фасады в SVG.

Файлы в корне: index.html, style.css, script.js.

Управление: физические KeyW/KeyA/KeyS/KeyD, KeyE, стрелки, drag камеры, колесо мыши, мобильный D-pad.
