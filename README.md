# Математическая школа №1 им. Х.И. Ибрагимова г. Грозного

## Концепция

Сайт начинается с приветствия:

**Добро пожаловать в Математическую школу №1 им. Х.И. Ибрагимова г. Грозного**

После нажатия «Войти в школу» остаётся только карта образовательного пространства.

## Удалено

- прежняя навигация;
- панели курсов;
- уровни и прогресс;
- XP;
- WASD и стрелки;
- клавиша E;
- перемещение карты;
- пользовательское масштабирование;
- перетаскивание карты;
- старые информационные панели.

## Файлы

- `index.html`
- `style.css`
- `script.js`
- `school-map.png` — исходная карта, сохранённая без перекодирования.
