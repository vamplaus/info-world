# Математическая школа №1 — финальный интерактивный проект

## Запуск
Откройте `index.html` в браузере. Для GitHub Pages загрузите в корень репозитория:

- `index.html`
- `style.css`
- `script.js`
- `school-map.png`

## Реализовано
- загрузка → автоматическое приветствие → автоматический переход к карте;
- фиксированная карта без drag/WASD/стрелок/масштабирования карты;
- 16 интерактивных зон, размеченных как SVG-контуры зданий, а не точки;
- реакция всей зоны здания при наведении и клике;
- полупрозрачная информационная карточка рядом с выбранным объектом;
- индивидуальные световые импульсы, контуры, кольца активности, окна и частицы;
- энергетические импульсы по дорогам;
- стартовая кинематографическая активация карты;
- без внешних библиотек и сетевых зависимостей.

Исходная карта сохранена без изменения композиции. Все эффекты добавляются поверх неё отдельными слоями.
