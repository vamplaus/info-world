# Математическая школа №1 — интерактивная живая карта V6

Финальная сборка содержит:
- 16 интерактивных объектов;
- отдельный контур и область наведения для каждого объекта;
- реакцию всей интерактивной области здания при наведении и клике;
- локальное увеличение и свечение выбранного объекта через SVG-клиппинг;
- детерминированные световые точки и импульсы без случайных фигурок;
- анимацию световых маршрутов;
- адаптивное масштабирование карты без её сжатия при открытии информации;
- информационную карточку, которая не является частью карты и удерживается в пределах экрана;
- адаптацию для широких и узких экранов;
- клавиатурное управление Enter/Space и закрытие по Esc.

Запуск: открыть index.html.
