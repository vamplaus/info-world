# Математическая школа №1 — живая интерактивная карта

Финальная сборка проекта для GitHub Pages.

## Файлы

В корне сайта должны находиться:

- `index.html`
- `style.css`
- `script.js`
- `school-map.png`

## Что реализовано

1. **Загрузка без показа карты** — изображение предварительно загружается до перехода к следующему экрану.
2. **Экран приветствия** — затем автоматически открывается вход в школьный город. Кнопка позволяет войти раньше автоматического перехода.
3. **Живое появление карты** — кинематографическое проявление, постепенное включение света и активация интерактивных точек.
4. **Кликабельные точки вместо больших зон** — область взаимодействия ограничена небольшой точкой над конкретным зданием; огромных прозрачных фигур поверх карты нет.
5. **Анимация жизни города**:
   - мерцание окон;
   - пульсирующее освещение зданий;
   - сигнальные огни на крышах;
   - расходящиеся световые кольца;
   - дорожные огни;
   - плавающие световые частицы;
   - мягкие локальные свечения;
   - периодический световой проход по сцене.
6. **Информационные окна** для всех направлений.
7. **Нет управления картой с клавиатуры**.
8. **Нет WASD, стрелок, E, drag, wheel zoom, pinch zoom или кнопок масштаба**.
9. Карта фиксирована и полностью адаптируется к размеру окна.

## Проверка

Перед упаковкой проверено:

- `script.js` проходит синтаксическую проверку JavaScript;
- `index.html` разбирается без ошибки;
- `school-map.png` присутствует;
- все четыре файла находятся в одной папке;
- имена файлов совпадают с подключениями в HTML.
