# INFO.WORLD — Living City Build

Это новая версия проекта, спроектированная как цельный интерактивный мир, а не схема с карточками.

## Главное изменение

- Центральный INFO CORE — визуальная доминанта города.
- Каждый район имеет собственную архитектуру и визуальную метафору.
- Python — кампус терминалов.
- Algorithm — логический метрополис и сеть узлов.
- AI — исследовательский купол и нейронная сеть.
- Web — башни, серверы и сетевые линии.
- Exam — отдельная арена испытаний.
- WASD / стрелки для движения.
- E для входа во взаимодействие.
- Клик по районам.
- Перетаскивание камеры и масштабирование.
- XP, уровни, открытие районов и localStorage.

## GitHub Pages

В корень репозитория нужно загрузить содержимое этой папки:

- index.html
- style.css
- script.js
- README.md

Не загружай папку целиком внутрь другой папки, если Pages публикуется из `/ (root)`.
