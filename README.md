# Mathematical School — Living Map

В этой версии исправлена ключевая проблема предыдущей сборки: интерактивной является не маленькая точка, а вся зона соответствующего здания.

## Файлы в корне репозитория
- index.html
- style.css
- script.js
- school-map.png

`school-map.png` — существующее изображение карты. Его нужно оставить в той же папке.

## Что реализовано
- загрузочный экран до показа карты;
- автоматический переход на экран приветствия;
- автоматический вход в карту;
- фиксированная карта без WASD, стрелок, drag и zoom;
- большие невидимые зоны поверх реальных зданий;
- при наведении реагирует вся зона здания;
- цветное внутреннее свечение;
- контур здания;
- пульсация;
- вспышка и ударная волна при клике;
- постоянные мигающие огни;
- частицы;
- последовательные огни на маршрутах;
- атмосферные световые проходы;
- адаптация для мобильных устройств.

Важно: это визуальная анимация поверх статического PNG. Само изображение здания физически не может менять отдельные нарисованные окна без исходного многослойного изображения/SVG. Поэтому эффект достигается слоями света, бликами, частицами и реакцией всей зоны здания.
