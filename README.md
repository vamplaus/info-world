# Интерактивная карта Математической школы №1

## Что работает

1. Экран загрузки карты.
2. Приветственный экран.
3. Кнопка «Открыть карту школы».
4. Интерактивные области на карте.
5. Нажатие на область открывает карточку направления.
6. Карта адаптируется к размеру экрана.

## Что намеренно отключено

- WASD;
- стрелки;
- E;
- управление камерой;
- перетаскивание;
- масштабирование колёсиком;
- масштабирование пальцами.
