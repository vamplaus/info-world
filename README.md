# Живая карта Математической школы №1

Файлы готовы для GitHub Pages:
- index.html
- style.css
- script.js
- school-map.png

Важно: в этой версии интерактивные зоны привязаны не к экрану, а к контейнеру изображения с исходным соотношением 1536×1024. Поэтому области зданий не смещаются при изменении размера окна.

Что изменено:
- каждая зона занимает область здания, а не точку;
- поверх каждого здания создаются десятки мерцающих окон;
- у каждого здания есть пульсирующее свечение крыши и маяки;
- при наведении появляется сканирующий свет и свечение всей зоны;
- при клике всё здание вспыхивает и даёт световую ударную волну;
- добавлены движущиеся световые импульсы по карте, световой проход, частицы и туман;
- карта фиксирована: нет WASD, стрелок, drag, wheel zoom и pinch zoom.
