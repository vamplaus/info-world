# Математическая школа №1 — финальная проверенная сборка

Файлы этой сборки согласованы между собой:

- `index.html`
- `style.css`
- `script.js`
- `school-map.png`

## Сценарий работы

1. Сначала показывается загрузка, карта скрыта.
2. После реальной загрузки `school-map.png` показывается экран приветствия.
3. Пользователь нажимает «ВОЙТИ В ШКОЛЬНЫЙ ГОРОД».
4. Появляется карта с кинематографическим проявлением, светом и частицами.
5. После завершения появления активируются кликабельные здания.
6. Клик по зданию открывает информационное окно.

## Важно

В проекте намеренно отсутствуют:

- WASD;
- управление стрелками;
- клавиша E;
- перемещение персонажа;
- перетаскивание карты;
- масштабирование колесом;
- pinch zoom;
- кнопки +/-.

Карта фиксирована. Интерактивность осуществляется только мышью или касанием по зонам.
